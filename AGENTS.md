# AGENTS.md

## Specs

Design specs and decisions live in [.agent/specs/](.agent/specs/). Read the relevant spec before changing an existing feature.

## Concise output

- Keep replies minimal: state the result, not the process.
- No preamble, no re-summarizing what was just done, no offers of further help.
- No code walkthroughs — cite `file:line` instead of re-explaining code.
- Prefer short lists over paragraphs.

## Conventions

See [CLAUDE.md](CLAUDE.md): pnpm, prettier (4 spaces, width 120), eslint, terraform layout.
